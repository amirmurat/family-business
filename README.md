# Family Business · РК1 — тренажёр

Мобильный статический сайт для подготовки к РК1 по «Финансам семейного бизнеса» в AlmaU. Создан для самостоятельного изучения на основе **скриншотов двух публичных Kahoot**, предоставленных студентом.

## Что внутри

| Набор | Вопросов | Язык |
| --- | ---: | --- |
| «Финансы семейного бизнеса: тест» | 27 | Русский |
| «RK_1_CASE» / компания Kokshe | 21 | Английский |
| Смешанный | 48 | Русский + английский |

- **Обучение:** сразу показывает правильность и объяснение.
- **Экзамен:** ответы скрыты до завершения; итоговая оценка и список ошибок.
- Повторение только вопросов, в которых была ошибка.
- Перемешивание вопросов и вариантов, переключение тестов.
- Локальное автосохранение незавершённой сессии в браузере.
- Управление с телефона, без изображений, установок, аналитики и внешних библиотек.

## Включить GitHub Pages

Этот репозиторий специально подготовлен для **Deploy from a branch**, без GitHub Actions и сборки.

1. Откройте **Settings → Pages** в репозитории `amirmurat/family-business`.
2. В **Build and deployment** выберите **Source: Deploy from a branch**.
3. Выберите **Branch: main**, папку **/(root)**, нажмите **Save**.
4. Дождитесь публикации в настройках Pages (обычно занимает несколько минут).
5. Ожидаемый адрес при стандартном имени аккаунта: `https://amirmurat.github.io/family-business/`. Пока Pages не включён, это **предполагаемый**, а не проверенный URL.

Главный файл — `index.html`. Содержимое вопросов — `questions.js`, логика — `app.js`, стили — `styles.css`.

## Точность и ограничения

- Вопросы и варианты восстановлены **по пользовательским скриншотам**, без автоматического получения оригинального Kahoot.
- Правильные варианты — **отмеченные галочкой в публичном Kahoot**, а не независимо удостоверенный официальный ключ экзамена.
- Для расчётных вопросов первого теста в пояснениях приведены формулы и проверка по цифрам вопроса.
- Во втором тесте **RK_1_CASE** не показана финансовая таблица компании Kokshe. Числовые ответы с отсутствующей исходной таблицей снабжены предупреждением «отмечен в Kahoot, независимо не проверен». Не придумывайте исходные данные.
- В вопросе об EAR 18% возможная формула через ежемесячное начисление приведена как допущение: период начисления не виден на скриншотах.
- Описание второго Kahoot — на литовском, сами вопросы — на английском. Сайт сохраняет английские формулировки и даёт русские объяснения.
- Сайт **не связан с преподавателем и Kahoot**, не гарантирует, что на очном РК1 будет один из этих тестов.

## Данные

Серверной части и отслеживания пользователей нет. Прогресс сохраняется **только локально** (localStorage) на том устройстве, на котором открыли сайт. Удаление данных браузера сбросит прогресс.

## Локальный запуск

Откройте `index.html` в браузере или запустите локальный статический сервер (не требуется npm):

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.
